Dieses plugin kann verwendet werden, um alle SonnenBatterie V2 API Werte
in kurzem Zeitintervall direkt an Loxone zu übermitteln.
Für schreibende Zugriffe können Virtuelle Output in Loxone konfiguriert werden.

Weil ausser dem Status alle API Werte authentifiziert werfolgen müssen,
wird das token der sonnenBatterie erfragt und auf dem Loxberry
zwischengespeichert.

Das Token kann via WebSchnittstelle der sonnenBatterie
bezogen (und auch cycled) werden.
